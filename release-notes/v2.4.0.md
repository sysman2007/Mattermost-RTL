## Mattermost RTL 2.4.0

### ✨ پوشه‌های پیام (اشتراکی و گروهی)
- از منوی پیام **«افزودن به پوشه…»** را بزنید. پوشه‌ها را در یک پنل مدیریت کنید: ساخت، افزودن و حذف پیام، و ترک پوشه.
- چهار نوع پوشه:
  - **شخصی:** فقط برای شما.
  - **مخاطب:** فقط برای شما و مرتبط با یک نفر؛ آن نفر هیچ دسترسی ندارد.
  - **اشتراکی:** شما و یک نفر دیگر.
  - **گروهی:** شما و حداکثر ۷ نفر دیگر (در کل ۸ نفر).
- ساخت و حذف پوشهٔ اشتراکی و گروهی فقط با تأیید همهٔ اعضا انجام می‌شود. درخواست‌های تأییدنشده بعد از ۷ روز منقضی می‌شوند.
- ترک پوشه آزاد است. اگر مالک برود، مالکیت به اولین عضو باقی‌مانده می‌رسد.
- پیام‌ها فقط با شناسه و محل‌شان ذخیره می‌شوند. اگر کسی به کانالی دسترسی نداشته باشد، پیام‌های آن کانال در پوشه‌اش نمایش داده نمی‌شوند.

### ⚙️ تنظیم مدیر
- **پوشه‌های پیام اشتراکی** در System Console ← Plugins ← Mattermost RTL؛ پیش‌فرض: خاموش. تا روشن نشود، گزینهٔ منو و API پوشه‌ها غیرفعال است.

### 📦 نصب / ارتقا
فایل `com.github.sysman2007.mattermost-rtl-2.4.0.tar.gz` را در **System Console ← Plugins ← Plugin Management** آپلود کنید. تنظیمات حفظ می‌شود.

**نیازمندی:** Mattermost Server 9.0.0 یا بالاتر روی لینوکس.
