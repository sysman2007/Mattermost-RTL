## Mattermost RTL 2.0.0

### ✨ قابلیت جدید: تبدیل «هوشمند (AI)» پیام به Markdown با LiteLLM
- در پنجرهٔ Markdown پیام (دکمهٔ **MD** یا منوی ⊞)، کنار «ساده» گزینهٔ **«هوشمند (AI)»** آمده است: متن پیام با مدل زبانی از طریق **LiteLLM** به یک سند Markdown مرتب تبدیل می‌شود — مناسب پیام‌های بی‌ساختار.
- خروجی با برچسب «تولیدشده با AI» نمایش داده می‌شود و پیش از کپی/دانلود قابل ویرایش است. در خطا یا شلوغی، نسخهٔ ساده نمایش داده می‌شود.
- **پیش‌فرض خاموش**؛ مدیر از **System Console ← Plugins ← Mattermost RTL** فعال می‌کند (آدرس، کلید، مدل، سقف توکن، timeout، محدودیت نرخ، حداکثر طول پیام، دستورالعمل اضافه).

### 🔐 امنیت و محافظت از سرور مدل
- مرورگر فقط **شناسهٔ پیام** را می‌فرستد؛ سرور دسترسی خواندن کانال را بررسی می‌کند و متن را خودش می‌خواند. **کلید API فقط روی سرور** است.
- یک درخواست هم‌زمان، محدودیت نرخ هر کاربر، `max_tokens` همیشه، `enable_thinking: false`، timeout و کشِ نتیجهٔ هر پیام.
- متن پیام‌ها و کلید در لاگ ثبت نمی‌شوند.

### ⚠️ تغییر معماری
- پلاگین از این نسخه **بخش سرور (Go)** دارد؛ بسته شامل باینری `linux-amd64` و `linux-arm64` است. نصب همچنان با یک آپلود انجام می‌شود.
- برای ساخت بسته از سورس، Go لازم است (`server/go.mod`).

### 📦 نصب / ارتقا
فایل `com.github.sysman2007.mattermost-rtl-2.0.0.tar.gz` را در **System Console ← Plugins ← Plugin Management** آپلود و پلاگین را Enable کنید. تنظیمات کاربران حفظ می‌شود. برای حالت AI، یک کلید مجازی LiteLLM جدا (alias پیشنهادی `mattermost-rtl`) بسازید و در تنظیمات پلاگین وارد کنید.

**نیازمندی:** Mattermost Server 9.0.0 یا بالاتر روی لینوکس (آزموده‌شده روی 11.11.1).
