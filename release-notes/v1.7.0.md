## Mattermost RTL 1.7.0

### ✨ قابلیت جدید: پیش‌نمایش فایل‌های Markdown
- کلیک روی پیوست `.md`، `.markdown` یا `.mdx` حالا سند **قالب‌بندی‌شده** را نشان می‌دهد، نه متن خام: عنوان، لیست و چک‌لیست، جدول، نقل‌قول، لینک و تصویر.
- **جهت هر بلوک جداگانه** تشخیص داده می‌شود (فارسی ← راست‌به‌چپ با Vazirmatn، انگلیسی ← چپ‌به‌راست)؛ کد همیشه چپ‌به‌راست.
- **رنگ‌آمیزی کد** با PrismJS (حدود ۳۰ زبان) با شماره خط و دکمهٔ Copy.
- **نمودار Mermaid** با تنظیم برای برچسب‌های فارسی؛ کتابخانه فقط برای اسنادی که نمودار دارند بارگذاری می‌شود.
- رنگ‌ها از تم روشن/تیرهٔ Mattermost پیروی می‌کنند.
- قابل خاموش کردن از **Settings ← Mattermost RTL (فارسی) ← پیش‌نمایش فایل Markdown** (پیش‌فرض: فعال).

### 🔐 امنیت
فایل‌ها را کاربران دیگر آپلود می‌کنند، پس سند در یک **iframe ایزوله** (`sandbox` بدون `allow-same-origin`، CSP سخت‌گیرانه) رندر می‌شود و به نشست، کوکی یا API دسترسی ندارد. HTML خام به چند تگ چیدمان محدود است، لینک‌ها فقط `http`/`https`/`mailto` هستند و Mermaid در حالت `strict` اجرا می‌شود.

### 📦 نصب / ارتقا
فایل `com.github.sysman2007.mattermost-rtl-1.7.0.tar.gz` را در **System Console ← Plugins ← Plugin Management** آپلود و پلاگین را Enable کنید. تنظیمات قبلی کاربران حفظ می‌شود.
اندازهٔ بسته به‌دلیل کتابخانهٔ Mermaid حدود ۳٫۶ مگابایت بزرگ‌تر شده است؛ این فایل فقط هنگام پیش‌نمایش سندی با نمودار دانلود می‌شود و روی بارگذاری عادی صفحه اثری ندارد.

**نیازمندی:** Mattermost Server 9.0.0 یا بالاتر (آزموده‌شده روی 11.11.1).

### 🙏 قدردانی
پارسر Markdown و تنظیم Mermaid برای فارسی از Maestro Markdown Viewer (Apache-2.0) اقتباس شده است. Mermaid و PrismJS تحت مجوز MIT.
