## Mattermost RTL 1.6.0

### ✨ قابلیت جدید: منوی راست‌کلیک روی پیام
- راست‌کلیک روی پیام، منوی **«بیشتر» (…) خود Mattermost** را کنار نشانگر موس باز می‌کند؛ همهٔ گزینه‌ها (پاسخ، جلو، ذخیره، یادآوری، پین، رونوشت، ویرایش، حذف و آیتم‌های پلاگین‌ها) همان رفتار و مجوزهای Mattermost را دارند.
- بالای منو ردیف دکمه‌های **نوار هاور پیام**: واکنش‌های اخیر، افزودن واکنش، ذخیره، عملیات و پاسخ.
- **منوی خود مرورگر حفظ می‌شود** روی لینک، تصویر، ویدیو، پیش‌نمایش فایل، کد، کادرهای نوشتن، نوار هاور و متن انتخاب‌شده؛ با **Shift + راست‌کلیک** همیشه منوی مرورگر باز می‌شود.
- در صفحهٔ راست‌به‌چپ، منو سمت چپ نشانگر باز می‌شود و همیشه داخل صفحه می‌ماند.
- قابل خاموش کردن از **Settings ← Mattermost RTL (فارسی) ← منوی راست‌کلیک پیام** (پیش‌فرض: فعال).

### 🔧 سایر تغییرات
- آزمون‌های واحد با `node --test` (بدون وابستگی) اضافه شد.

### 📦 نصب / ارتقا
فایل `com.github.sysman2007.mattermost-rtl-1.6.0.tar.gz` را در **System Console ← Plugins ← Plugin Management** آپلود و پلاگین را Enable کنید. تنظیمات قبلی کاربران حفظ می‌شود.

**نیازمندی:** Mattermost Server 9.0.0 یا بالاتر (آزموده‌شده روی 11.11.1).
