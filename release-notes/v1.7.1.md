## Mattermost RTL 1.7.1

### 🔧 بهبود
- **فهرست مطالب پیش‌نمایش md** حالا با کلیک در هر جای بیرون از پنل (داخل سند یا بیرون از پیش‌نمایش) بسته می‌شود؛ قبلاً فقط با ☰، Esc یا انتخاب سرفصل بسته می‌شد.

### 📦 نصب / ارتقا
فایل `com.github.sysman2007.mattermost-rtl-1.7.1.tar.gz` را در **System Console ← Plugins ← Plugin Management** آپلود و پلاگین را Enable کنید. تنظیمات کاربران حفظ می‌شود.

**نیازمندی:** Mattermost Server 9.0.0 یا بالاتر (آزموده‌شده روی 11.11.1).
