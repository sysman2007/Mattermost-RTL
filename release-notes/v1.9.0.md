## Mattermost RTL 1.9.0

### ✨ قابلیت جدید: نمایش و دانلود پیام به‌صورت Markdown
- دکمهٔ **MD** در نوار هاور پیام (کنار دکمه‌های تنظیم جهت) و گزینهٔ **«نمایش به‌صورت Markdown»** در منوی ⊞ Message actions.
- متن سادهٔ پیام **هوشمند** به یک سند Markdown مرتب تبدیل می‌شود — کاملاً در مرورگر و بدون ارسال به هیچ سرویسی:
  - جداکننده‌های `═══` و خطِ قاب‌گرفته بینشان ← خط افقی و سرفصل
  - «بخش الف) …»، «۱) …» ← سرفصل؛ بلوک‌های `{…}` ← بلوک کد؛ لیست‌ها با حفظ تودرتویی؛ «⚠️ / نکته:» ← نقل‌قول
  - خطِ کوتاهِ تنها بین دو خط خالی ← سرفصل؛ «برچسب:» + چند خط ← لیست؛ بلوکِ «کلید: مقدار» ← لیست با کلیدِ پررنگ؛ «اقدام تیم: …» ← کلیدِ پررنگ
  - مسیر API، مسیر و نام فایل، دامنه، شناسه‌های کد و هش کامیت ← کد درون‌خطی؛ متن فارسی و لینک‌ها دست نمی‌خورند
  - نویسنده، کانال و تاریخ پیام بالای سند
- پنجرهٔ **پیش‌نمایش** و **متن Markdown** (قابل ویرایش)، با **کپی** و **دانلود .md**.
- قابل خاموش کردن از **Settings ← Mattermost RTL (فارسی) ← خروجی Markdown پیام** (پیش‌فرض: فعال).

### 📦 نصب / ارتقا
فایل `com.github.sysman2007.mattermost-rtl-1.9.0.tar.gz` را در **System Console ← Plugins ← Plugin Management** آپلود و پلاگین را Enable کنید. تنظیمات کاربران حفظ می‌شود.

**نیازمندی:** Mattermost Server 9.0.0 یا بالاتر (آزموده‌شده روی 11.11.1).
