## Mattermost RTL 1.8.0

### ✨ قابلیت جدید: پیش‌نمایش CSV، TSV و JSON
- **CSV/TSV به‌صورت جدول:** سرستون ثابت هنگام اسکرول، شمارهٔ ردیف، تشخیص خودکار جداکننده (کاما، نقطه‌ویرگول، تب، `|`) و پشتیبانی کامل از فیلدهای نقل‌قول‌دار (کاما و خط جدید داخل فیلد).
- **جهت هر سلول جداگانه:** سلول فارسی راست‌به‌چپ، انگلیسی چپ‌به‌راست؛ اعداد (حتی با ارقام فارسی) همیشه چپ‌به‌راست و راست‌چین.
- **JSON مرتب‌شده** با رنگ‌آمیزی، خلاصهٔ ساختار و دکمهٔ Copy؛ JSON نامعتبر با پیام خطا و متن خام.
- مثل پیش‌نمایش Markdown در iframe ایزوله رندر می‌شود.
- قابل خاموش کردن از **Settings ← Mattermost RTL (فارسی) ← پیش‌نمایش فایل CSV و JSON** (پیش‌فرض: فعال).

### 📦 نصب / ارتقا
فایل `com.github.sysman2007.mattermost-rtl-1.8.0.tar.gz` را در **System Console ← Plugins ← Plugin Management** آپلود و پلاگین را Enable کنید. تنظیمات کاربران حفظ می‌شود.

**نیازمندی:** Mattermost Server 9.0.0 یا بالاتر (آزموده‌شده روی 11.11.1).
