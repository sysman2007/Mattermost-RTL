## Mattermost RTL 2.3.1

### ✨ پیش‌نمایش صفحهٔ HTML
- فایل‌های `.html` و `.htm` پیش‌فرض به‌صورت **خود صفحه** نمایش داده می‌شوند، نه متن کد.
- صفحه داخل iframe با `sandbox` خالی و CSP است: اسکریپت اجرا نمی‌شود، به API یا کوکی‌های Mattermost دسترسی ندارد و نمی‌تواند صفحهٔ والد را جابه‌جا کند. تصویر، استایل و فونت (از `http`/`https` و `data:`) نمایش داده می‌شوند.
- برای دیدن کد با رنگ‌آمیزی Prism، تب **کد** را بزنید (همان نمای نسخهٔ 2.3.0).
- پس‌زمینهٔ پیش‌نمایش سفید است، چون بیشتر صفحه‌ها برای زمینهٔ سفید طراحی شده‌اند؛ حتی در تم تیره.
- لینک‌های داخل صفحه فعال نیستند.

### 📦 نصب / ارتقا
فایل `com.github.sysman2007.mattermost-rtl-2.3.1.tar.gz` را در **System Console ← Plugins ← Plugin Management** آپلود کنید. تنظیمات حفظ می‌شود.

**نیازمندی:** Mattermost Server 9.0.0 یا بالاتر روی لینوکس.
