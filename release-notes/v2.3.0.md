## Mattermost RTL 2.3.0

### ✨ پیش‌نمایش فایل‌های کد با Prism
- پیوست‌های کد (js، ts، py، cs، java، go، sql، yaml، sh، ps1، html، css، Dockerfile و…) با رنگ‌آمیزی PrismJS، شمارهٔ خط و دکمهٔ Copy در فریم ایزوله باز می‌شوند؛ کامنت‌های فارسی داخل کد درست نمایش داده می‌شوند.
- تنظیم کاربر: **پیش‌نمایش فایل‌های کد** (پیش‌فرض: فعال برای همهٔ فایل‌های کد؛ خاموش ← پیش‌نمایش Mattermost).

### ✨ انتخاب زبان هنگام چسباندن کد
- با چسباندن کد در کادر پیام، نواری زبان را حدس می‌زند و می‌توانید آن را عوض کنید:
  - **قرار دادن در بلوک کد** با زبان درست — Mattermost آن را رنگ‌آمیزی می‌کند؛
  - **تنظیم زبان** برای بلوک ``` بدون زبانی که داخلش چسبانده‌اید؛
  - **ارسال به‌صورت فایل** برای کد بلند.
- متن عادی نوار کد نمی‌گیرد؛ paste عادی مسدود نمی‌شود. تنظیم کاربر: **زبان کد هنگام چسباندن**.

### 📦 نصب / ارتقا
فایل `com.github.sysman2007.mattermost-rtl-2.3.0.tar.gz` را در **System Console ← Plugins ← Plugin Management** آپلود کنید. تنظیمات حفظ می‌شود.

**نیازمندی:** Mattermost Server 9.0.0 یا بالاتر روی لینوکس (آزموده‌شده روی 11.11.1).
