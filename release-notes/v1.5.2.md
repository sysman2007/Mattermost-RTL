## Mattermost RTL 1.5.2

پلاگین فارسی‌سازی Mattermost: bidi هوشمند برای هر پیام، جهت راست‌به‌چپ برای کل صفحه، فونت‌های فارسی و منوی کناری جمع‌شونده.

### ⚠️ تغییر ناسازگار: شناسهٔ پلاگین عوض شده است
- شناسهٔ جدید: `com.github.sysman2007.mattermost-rtl` (شناسهٔ قبلی: `com.ibarsam.barsam`)
- نام نمایشی جدید: **Mattermost RTL**
- Mattermost این نسخه را یک **پلاگین جدید** می‌بیند. نسخهٔ قبلی به‌روزرسانی نمی‌شود.
- **تنظیمات کاربران به پیش‌فرض برمی‌گردد**، چون هم ترجیحات سمت سرور و هم کلیدهای ذخیره‌شده در مرورگر کلید جدید دارند. کاربران باید تنظیماتشان را دوباره در **Settings ← Mattermost RTL (فارسی)** انتخاب کنند.

### 🐞 رفع باگ
- **درگ معکوس جداکنندهٔ پنل‌ها در RTL:** وقتی صفحه راست‌به‌چپ بود، کشیدن جداکنندهٔ پنل پاسخ (RHS) یا منوی کناری (LHS) آن را در جهت مخالف حرکت می‌داد. حالا جداکننده همراه نشانگر موس حرکت می‌کند. این اصلاح فقط هنگام درگ روی دستگیرهٔ تغییر اندازه و فقط در حالت RTL فعال است و رفتار LTR دست نمی‌خورد.

### 🔧 سایر تغییرات
- مخزن از این نسخه تحت مجوز **Apache License 2.0** منتشر می‌شود. فونت‌ها مجوز خودشان را دارند (Vazirmatn و Noto Nastaliq Urdu تحت SIL OFL 1.1).
- همهٔ ارجاع‌ها به نام قبلی پلاگین از کد و مستندات حذف شد. پیشوند کلاس‌های CSS و ویژگی‌های `data-*` هم به `mmrtl` تغییر کرد.

### 📦 نصب / ارتقا
1. در **System Console ← Plugins ← Plugin Management**، پلاگین قبلی (`com.ibarsam.barsam`) را **غیرفعال و حذف** کنید تا دو نسخه هم‌زمان اجرا نشوند.
2. فایل `com.github.sysman2007.mattermost-rtl-1.5.2.tar.gz` را از همین Release دانلود کنید و از همان صفحه **Upload** کنید.
3. پلاگین را **Enable** کنید.
4. اگر افزونهٔ کروم مشابهی نصب است، روی دامنهٔ چت غیرفعالش کنید.

**نیازمندی:** Mattermost Server 9.0.0 یا بالاتر.
