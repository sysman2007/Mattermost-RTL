## Mattermost RTL 2.3.2

### 🐛 رفع باگ
- متن بلندی که کد است (مثل یک صفحهٔ HTML) و به‌صورت فایل `.md` پیوست می‌شود، اکنون داخل بلوک کد با زبان درست قرار می‌گیرد. قبلاً بدون بلوک کد ذخیره می‌شد و پیش‌نمایش Markdown تگ‌ها را به‌صورت متن معمولی نشان می‌داد.
- نسخهٔ «مرتب‌شدهٔ» `.md` هم همین رفتار را دارد.
- متن فارسی معمولی تغییری نکرده است.

### 📦 نصب / ارتقا
فایل `com.github.sysman2007.mattermost-rtl-2.3.2.tar.gz` را در **System Console ← Plugins ← Plugin Management** آپلود کنید. تنظیمات حفظ می‌شود.

**نیازمندی:** Mattermost Server 9.0.0 یا بالاتر روی لینوکس.
