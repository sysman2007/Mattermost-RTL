## Mattermost RTL 2.2.0

### ✨ قابلیت جدید: چسباندن متن بلند به‌صورت فایل .md
- بعد از چسباندن متن بلند (۱۰ خط یا ۱۰۰۰ کاراکتر به بالا) در کادر پیام یا پاسخ، نواری پیشنهاد می‌دهد:
  - **ارسال به‌صورت فایل .md** — همان متن، به‌صورت پیوست
  - **فایل .md مرتب‌شده** — با تبدیل Markdown ساده (سرفصل، لیست، کد درون‌خطی…)
  - **همان متن** — رفتار عادی
- پیوست از مسیر چسباندن فایل خود Mattermost اضافه می‌شود؛ پیش از ارسال می‌توانید توضیح بنویسید. در کانال یک کارت کوچک دیده می‌شود که در پیش‌نمایش md باز می‌شود.
- paste عادی مسدود نمی‌شود؛ متن‌های کوتاه، فایل‌ها و تصاویر دست نمی‌خورند؛ همه‌چیز در مرورگر انجام می‌شود.
- قابل خاموش کردن از **Settings ← Mattermost RTL (فارسی) ← چسباندن متن بلند به‌صورت فایل**.

### 📦 نصب / ارتقا
فایل `com.github.sysman2007.mattermost-rtl-2.2.0.tar.gz` را در **System Console ← Plugins ← Plugin Management** آپلود کنید. تنظیمات حفظ می‌شود.

**نیازمندی:** Mattermost Server 9.0.0 یا بالاتر روی لینوکس (آزموده‌شده روی 11.11.1).
