## Mattermost RTL 2.1.0

### ✨ قابلیت جدید: تیک دیده‌شدن پیام‌ها (✓ / ✓✓) — اختیاری
- زیر پیام‌های خودتان: **✓** ارسال شد، **✓✓** (آبی) دیده شد؛ در گروه‌ها نام بینندگان (تا ۳ نفر) یا «۳ از ۵».
- برای همهٔ انواع کانال، از جمله کانال‌های خصوصی و پیام‌های مستقیم.
- **پیش‌فرض خاموش**؛ مدیر از **System Console ← Plugins ← Mattermost RTL ← تیک دیده‌شدن پیام‌ها** فعال می‌کند.

### 🔐 حریم خصوصی و شفافیت
- **اطلاع‌رسانی یک‌باره به هر کاربر** پیش از هر نمایش؛ تا کاربر «متوجه شدم» را نزند، وضعیت دیده‌شدنش برای کسی گزارش نمی‌شود و خودش هم تیکی نمی‌بیند.
- **زمان دقیق دیدن هرگز نمایش داده نمی‌شود**؛ سرور فقط «دیده شد / نشد» را برای پیام‌های خودِ کاربر برمی‌گرداند.
- فقط اعضای دارای دسترسی خواندن کانال پاسخ می‌گیرند؛ بات‌ها شمرده نمی‌شوند؛ جز تأیید اطلاعیه دادهٔ تازه‌ای ذخیره نمی‌شود.
- پیشنهاد: پیش از فعال‌سازی، در کانال عمومی سازمان هم اطلاع‌رسانی کنید و سیاست داخلی/قانونی محل خود را بررسی کنید.

### 🔧 سایر تغییرات
- **آدرس پیش‌فرض LiteLLM حذف شد**؛ تا مدیر آدرس را وارد نکند، تبدیل هوشمند خاموش می‌ماند (بقیهٔ پلاگین بدون خطا کار می‌کند).

### 📦 نصب / ارتقا
فایل `com.github.sysman2007.mattermost-rtl-2.1.0.tar.gz` را در **System Console ← Plugins ← Plugin Management** آپلود کنید. ⚠️ اگر در 2.0.0 آدرس LiteLLM را تغییر نداده بودید (پیش‌فرض)، پس از ارتقا آن را دستی وارد کنید.

**نیازمندی:** Mattermost Server 9.0.0 یا بالاتر روی لینوکس (آزموده‌شده روی 11.11.1).
